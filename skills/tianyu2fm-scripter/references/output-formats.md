# Output formats

Choose the smallest format that satisfies the request.

## Research question bank

Use when the user asks for additional questions from a guest's works.

```text
## 延续性提问

1. [Question]
   出处：《Work》｜Chapter or section

## 核心转化

1. [Question]
   出处：《Work》｜Chapter or section
```

Add a short transparency note when only previews, tables of contents, or excerpts were available.

## Three-part episode outline

Use when the user asks to arrange an episode and does not request finer subdivision.

```text
# 第一部分｜[One compelling large question]

- [Supporting question]
- [Supporting question]

# 第二部分｜[One compelling large question]

- [Supporting question]
- [Supporting question]

# 第三部分｜[One open, personal large question]

- [Supporting question]
- [Supporting question]
```

Do not add subheadings between the large question and its supporting questions.

## Source labels

- Use `出处` for a directly supported book chapter, excerpt, essay, or statement.
- Use `灵感来源` for a transformation or inference inspired by the source.
- Use `待核` when the claim has only appeared in a secondary account.

Never invent page numbers. Prefer chapter or section labels when pagination differs by edition.

## Document delivery checklist

- Keep the source document unchanged unless the user explicitly authorizes editing it.
- When creating a child page, verify the parent-child relationship after creation.
- Re-fetch the written page and compare question stems against the source list.
- Return a clickable link and a one-sentence description of the arrangement logic.
