# TIANYU2FM 话题分段标准

## 角色与核心判断

主持人是天宇和天域。优先把主持人开启新方向的问题作为新段落起点。嘉宾或其他人提出的问题，只有在它实质性开启独立讨论时才可分段。

每个候选点都问：从这里开始，听众是否进入了一段可以独立命名的新讨论？若只是当前议题的解释、举例、追问、反问或修辞，继续留在原段。

## 应当分段

- 主持人明确宣布“下一个话题”并提出新问题。
- 问题改变讨论对象、因果方向、时间尺度或实践目标。
- 新问题即使从前文自然引出，也能形成数分钟的独立讨论。
- 嘉宾向主持人提出了真正改变议题方向的问题。
- 成片从一个话题的回答中间开始：在 `0.0` 建立第一段，并依据现有讨论命名。

## 不应分段

- 要求补充细节、数据、例子或操作步骤。
- 对同一主问题的连续追问，哪怕句式是问句。
- 嘉宾用反问回答主持人。
- 陈述中顺带抛出的微小问题，没有改变讨论方向。
- 寒暄、流程提示、录制说明、广告口播或剪辑意见。
- 仅凭摄像机切换、静音、B-roll、marker 或标题注释判断出的边界。

## 起点与覆盖范围

- 起点取新话题问题第一个字的成片时间码；不要取嘉宾回答的开头。
- 若主持人先用一句简短过渡明确引出新话题，起点可以取过渡句开头。
- block 从本段起点持续到下一段起点。
- 最后一段持续到项目 sequence 结束。
- 时间必须来自逐字稿或字幕；不按文字长度估算。

## 标题要求

- 必须是问句。
- 提炼本段真正回答的核心，而非照抄主持人的口语原句。
- 通常 15–25 个汉字，简洁、有洞察力、脱离上下文也能理解。
- 可使用反差、意外性或好奇心，但不得夸大原文没有讨论的结论。
- 避免泛题：如“关于焦虑的讨论”“你是怎么开始的？”。

示例：

- `焦虑的主人为什么会养出焦虑的猫？`
- `惩罚为什么反而会让猫更具攻击性？`
- `对猫来说，怎样的一生才算真正幸福？`

## 最终复核

逐段检查：

1. 标题是否覆盖该 block 内最主要的讨论，而非只覆盖开头一句。
2. 下一段是否真的由独立问题开启。
3. 连续段落是否只是同一议题的同义拆分。
4. 所有标题是否为问句且长度自然。
5. 第一段从 `0.0` 开始、最后一段覆盖到 sequence 结束。
